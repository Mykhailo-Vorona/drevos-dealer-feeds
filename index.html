DREVOS dealer feeds

Public retail catalog data for dealers. Refreshed daily. Prices are regular retail prices before source-site discounts; dealers set their own promotions. Products are made to order, so stock quantities are intentionally omitted. Removed products remain marked as deleted.

How to use / Как пользоваться:
Open / Открыть shows the direct static feed URL used for automatic updates. XML and JSON will look like technical text — this is normal.
Download / Скачать saves the selected file to your Downloads folder.
